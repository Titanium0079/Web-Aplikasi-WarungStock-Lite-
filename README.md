# WarungStock Lite 📦

**Modern Inventory Management Dashboard for Indonesian UMKM**

WarungStock Lite is a lightweight inventory management web application designed to help small businesses manage their product stock, inventory movements, and transactions efficiently.

## ✨ Features

- 📊 Interactive inventory dashboard
- 📦 Product management (CRUD)
- 📥 Stock-in management
- 📤 Stock-out management
- ⚠️ Automatic low-stock alerts
- 📋 Transaction history
- 📈 Inventory analytics
- 💾 LocalStorage data persistence
- 📱 Responsive user interface

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Chart.js
- JSON
- Browser LocalStorage

warungstock-lite/

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension if needed.
4. Run `index.html` using Live Server.

## 💾 Data Storage

The application uses JSON for initial product data and Browser LocalStorage for persistent local changes.

No SQL database or external backend is required.

## 🎯 Project Purpose

This project demonstrates a simple, accessible, and lightweight inventory management solution for Indonesian small businesses.
